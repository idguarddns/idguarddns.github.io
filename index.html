Panduan Konfigurasi

Petunjuk ringkas untuk memasang IDGUARD di berbagai perangkat.

📱 Android (Private DNS) ↓

1. Buka Pengaturan > Jaringan & Internet > DNS Pribadi.

2. Pilih mode Nama Host Penyedia DNS Pribadi.

3. Masukkan hostname: dns.idguard.ai.id lalu simpan.

🌐 Browser (Chrome / Brave / Edge / Firefox) ↓

1. Buka menu Settings > Privacy and Security.

2. Aktifkan opsi Use secure DNS.

3. Pilih Custom dan masukkan URL DoH: https://dns.idguard.ai.id/dns-query

📡 MikroTik RouterOS v7 (DoH) ↓

Jalankan perintah berikut pada Terminal MikroTik:

/tool fetch url="https://curl.se/ca/cacert.pem" download=yes
/certificate import file-name=cacert.pem passphrase=""
/ip dns set use-doh-server="https://dns.idguard.ai.id/dns-query" verify-doh-cert=yes
/ip dns cache flush
